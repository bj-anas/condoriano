# Friend List

The Friend List is a messaging feature for keeping a list of friends, seeing who is online and chatting with them. This page covers adding friends, 1:1 chat, limits and groups.

## Friend List: overview and how to open it

Open the Friend List by pressing the N key, or from the main menu (hotkey: Esc). You add Adventurers using their family name and can chat with them in the same window. The list shows who is online, or how long ago offline friends were last on, along with their class icon, character level, and family and character names. Right-click a friend's name for options: invite to a party, remove from the list, start a 1:1 chat, or whisper. A whisper is the traditional private message and uses the main chat window system.

## Friend List: 1:1 chat

A 1:1 chat lets you message a friend inside the Friend List window, outside the regular chat window, which makes each conversation easier to follow. It supports emojis, including animated ones. The latest message from a friend in a 1:1 chat pops up in the bottom right of your screen.

## Friend List: sending friend requests

Press the Add Friend button and enter the other Adventurer's family name. The receiver must accept the request. The New Requests button opens the Friend Requests window, which shows the status of requests you sent and received. When you receive a request, an alert icon appears at the bottom right of your screen.

## Friend List: friend limit and what to do about it

The Friend List has a limit on total accepted friends, counting both those you invited and those who invited you. When you reach it you cannot add more. To free space, remove inactive friends by right-clicking them in the list, and clear pending requests, since unaccepted sent and received requests also count toward the limit. Also make sure neither of you is on the other's block list. After many quick changes to the list, restarting the game client is recommended.

## Friend List: groups

New friends go into the Default group. To sort friends, press the Add Group button to create a group. Click the three dots to the right of a group's name to rename or delete it. Group names can be changed whenever you like. The wiki suggests, for example, a group for friends you party with in Atoraxxion dungeons.
