# Chat Window

The Chat Window is where players talk to each other and read system messages. This page covers chat types and their shortcuts, window settings, highlighting, name display, macros, reporting and social actions.

## Chat window: sending a message

To chat, press the Enter key to open the chat input box, type the message, and press Enter again to send it. Two buttons sit to the right of the input box. The M button opens the chat macro settings, and the S button opens the social action window.

## Chat window: chat types for nearby and server players

The Chat Window has several chat types, each shown in its own color with the type labeled left of the message. How to select each one while the input box is open:

| Chat type | Shortcut | Slash command | Who sees it |
| --- | --- | --- | --- |
| General Chat | Alt+1 | /s | Nearby Adventurers only |
| Server Group | Alt+2 | /y | Everyone in the same server group (for example Balenos 1-3); each message costs 1 Energy |
| Whisper | Alt+3 | /w | One Adventurer, by character or family name; /r replies to the last person you whispered |
| World | Alt+6 | /a | Everyone on all server channels; needs a megaphone item (available in the Pearl Shop) and costs 1 energy per message |

A Notice is a different kind of message: it comes from a Game Master, appears in light yellow at the top of the screen and in the chat window, and warns about issues, events and maintenance.

## Chat window: group chat types (party, guild, alliance, team)

These chat types are only seen by the relevant group, and you can use each only while you belong to it:

| Chat type | Shortcut | Slash command | Who sees it |
| --- | --- | --- | --- |
| Party | Alt+4 | /p | Members of your party |
| Guild | Alt+5 | /g | Members of your guild |
| Guild Alliance | Alt+- | /u | Members of your guild alliance |
| Team | Alt+0 | /t | Used while taking part in the Red Battlefield |

Staff chat is for the guild master and the guild's advisors and officers. Other types are Chat Group (Alt+7, shared with others in the same Chat Group), Roleplay (Alt+8) and Arsha (Alt+9, for the Arena of Arsha). The Combat (Death) type shows combat system messages. The System option toggles Central Market notifications, worker task updates, items you obtained, items your party obtained, enhancement alerts and farming information.

## Chat window: settings and separate windows

Hover over the chat window and click the cogwheel icon to open Chat Window Settings. There you set transparency, which chat types show, font size and more. Click the color square beside a chat type to change its color. You can also toggle scroll animation, emoji animations, chat name and timestamps, and view your blocked Adventurers list.

The Separate Chat Window button next to a chat name pulls that chat into its own window, useful for showing only party, guild or server group chat. The new window appears in the screen center. To move it, toggle the lock button and drag with the four-arrow icon. Press the + icon next to its chat name to merge it back. Use the transparency slider for a solid or fully transparent background.

## Chat window: blocking and reporting players

To block an Adventurer, left-click their name in chat and press Block. Their messages then become invisible to you. To report inappropriate chat, click the Adventurer's name and press the Report Chat button. In the Report Chat window, select the conversation and write the reason. The report automatically includes part of the chat history, so no screenshot ticket to Support is needed.

## Chat window: highlight with @name

Typing @ followed by a character name and then your message highlights that name in light green for the named Adventurer, and they hear a notification sound. This helps in busy party, guild or team chat when you want one person to notice your message.

## Chat window: family name versus character name display

Choose whether chat shows family names or character names in the Show/Hide section of the General Settings window, opened from the main menu (hotkey: Esc). When whispering, the Family or Character button on the left of the input switches the mode, and this also changes the game setting. The mode decides which kind of name you type when whispering.

## Chat window: chat macros

Press the M button to the right of the chat input box to set up chat macros. You can save phrases you use often and assign shortcuts to them.

## Chat window: social actions

After opening the chat input with Enter, press the S button to open the Social Action window. Actions with the same name can look different depending on the character and gender. They suit taking screenshots. You can also trigger an action by typing a command or keyword you set, without opening the window. Some special social actions have unlock conditions, usually completing certain quests, and some need a specific title. Hover over the icon of an action to see how to unlock it.
