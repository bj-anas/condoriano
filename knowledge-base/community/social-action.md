# Social Action

A short wiki page that lists social actions (emote-style actions) with the classes that can use each one. The page text is mostly empty, so few details are available.

## Social Action: list of actions on the wiki

The Social Action page names seven social actions: Behold Me!, Petal Power, Ta-da!, Casual Salute, Respectful Bow, Too Easy and Say My Name. Each one is shown in a table split into Male Class and Female class columns. In the text available, only the first action, Behold Me!, has entries filled in: Berserker under male classes and Shai under female classes. The other six tables are empty in the text. The page gives no unlock method, hotkey or other detail about how to obtain or use these actions.
