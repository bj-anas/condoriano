# Glossary

Player slang mapped to official in-game names. Each table row is also used to expand search
queries, so keep the format `| slang | official name | meaning |`.

## Enhancement terms: PRI, DUO, TRI, TET, PEN, FS, Valks, Crons

| slang | official name | meaning |
|---|---|---|
| PRI | I (Primary) | First enhancement level after +15 for gear, or the first level for accessories |
| DUO | II (Duo) | Second enhancement level, after PRI |
| TRI | III (Tri) | Third enhancement level, after DUO |
| TET | IV (Tetra) | Fourth enhancement level, after TRI |
| PEN | V (Penta) | Fifth and highest enhancement level, after TET |
| FS | Failstack | Bonus enhancement chance gained from failed attempts |
| Valks | Advice of Valks | Item that gives a fixed number of failstacks |
| Crons | Cron Stone | Stone that prevents an enhancement level from dropping on failure |
| Conc | Concentrated Magical Black Stone | Stone used to enhance gear from PRI to PEN |
| Memfrags | Memory Fragment | Item that restores max durability |

## Stats terms: AP, AAP, DP

| slang | official name | meaning |
|---|---|---|
| AP | Attack Power | Main damage stat for main and sub weapons |
| AAP | Awakening Attack Power | Attack power used by awakening skills |
| DP | Defense Power | Main defensive stat |

## General terms: CM, CP, LS

| slang | official name | meaning |
|---|---|---|
| CM | Central Market | The player marketplace where items are bought and sold |
| CP | Contribution Points | Points used to rent houses and nodes |
| LS | Life Skill | Non-combat skills such as gathering, fishing, cooking and alchemy |
