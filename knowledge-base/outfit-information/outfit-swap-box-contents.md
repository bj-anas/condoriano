# Outfit Swap Box Contents

What the Outfit Swap Box is, and which exclusive outfit set each class receives from Outfit Swap Box I and Outfit Swap Box II.

## Outfit Swap Box: what it is

The Outfit Swap Box is an outfit box that lets a character wear the exclusive outfits that belong to other classes. Items obtained from an Outfit Swap Box cannot be registered on the Central Market. The details of the class-specific outfits are shown in the item description.

## Woosa and Maegu Flamekissed and Moonflower swap

The Outfit Swap Box page lists a separate Flamekissed and Moonflower swap for the Woosa and Maegu classes. In it, the Woosa receives the Flamekissed Outfit Set and the Maegu receives the Moonflower Outfit Set.
