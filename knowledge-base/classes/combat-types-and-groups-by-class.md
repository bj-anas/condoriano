# Combat Types and Groups by Class

Explains Combat Type, the Vanguard, Pulverizer and Skirmisher class groups, and Super Armor damage reduction, with a list for every class.

## Combat Type of a class

Some item effects, such as those from artifacts and lightstones, depend on the character's Combat Type. A character's Combat Type is set by the main weapon and stays the same whether the character chooses Succession or Awakening. For example, an Awakening Ranger who uses the Kamasylven Sword still counts as Ranged, because her main weapon is the longbow. A character's combat type can be checked under Battle Stats in My Information (P).

## Class groups: Vanguard, Pulverizer and Skirmisher

Each class is in one of three groups, Vanguard, Pulverizer or Skirmisher, and its group can change between Succession and Awakening. Each group has a +5% damage edge over one other group:

| Group | Deals +5% extra damage to |
|---|---|
| Vanguard | Pulverizer |
| Skirmisher | Vanguard |
| Pulverizer | Skirmisher |

## Super Armor and Super Armor damage reduction

Some skills grant Super Armor, and a Super Armor icon appears above the character while it is active. During Super Armor the character is immune to CC effects, except Grapples, and takes reduced damage. The default damage reduction during Super Armor is 10%. Some classes and Succession or Awakening states have a different value, and those values are listed by class on the wiki.

## Melee classes with a single group

Shai, Scholar, Wukong and Seraph are Melee classes that have one group in every state. The wiki gives each a single Super Armor damage reduction value.

| Class | Group | Super Armor damage reduction |
| --- | --- | --- |
| Shai | Vanguard | 20% |

| Seraph | Skirmisher | 20% |

## Ranged classes by group and Super Armor

The Ranged classes are Ranger, Archer and Deadeye. None of them has a special Super Armor value, so all use the default 10%. Ranger is Pulverizer in Succession and Skirmisher in Awakening. Archer is listed with a single group, Pulverizer. Deadeye is also listed with a single group, Pulverizer.
