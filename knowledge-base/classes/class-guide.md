# Class Guide

Overview of Black Desert's playable classes and of the Succession and Awakening choice that every class makes at level 56.

## Black Desert classes overview

The wiki's Class Guide says Black Desert has a total of 29 different classes. Players pick a class that fits their taste, whether that is plate armor, heavy axes, dark magic, shadow strikes or ranged attacks with bows. Each class also has its own growth path through Succession or Awakening. The class list on the page has these names: Warrior, Ranger, Sorceress, Berserker, Tamer, Musa, Maehwa, Valkyrie, Kunoichi, Ninja, Wizard, Witch, Dark Knight, Striker, Mystic, Lahn, Archer, Shai, Guardian, Hashashin, Nova, Sage, Corsair, Drakania, Woosa, Maegu, Scholar, Dosa, Deadeye and Wukong. That list shows 30 names, while the page text says 29.

## Succession and Awakening choice at level 56

Once a character reaches level 56, the player can choose between Succession and Awakening. The choice decides which weapons and skills the character has. With Succession, the character keeps the same combat system as before. With Awakening, the character gets a new type of weapon called an Awakening Weapon, which opens up a different style of gameplay.

## Succession and Awakening example with Warrior

Before choosing, a Warrior at levels 1 to 55 uses a Longsword and Shield as basic weapons. If the player picks Succession, Warrior masters the Longsword and Shield. If the player picks Awakening, Warrior fights in a new style with the Great Sword.

## Switching between Succession and Awakening

Players do not need to commit to one choice forever. A player who is unsure can try both states. After completing both the Succession questline and the Awakening questline, the player can switch between the two states by resetting the character's skill points.

## Class attribute ratings and difficulty

The Class Guide page shows each class's attributes as images that give five ratings: Attack, Defense, Evasion, Combo and Control Difficulty. The ratings are shown in the images and are not written in the page text. Clicking a class image opens that class's own page.
