# Trial Character

The Trial Character system lets players try a class at high level in a limited area. This page covers what it is, how to make one, and what to do with it.

## Trial Character overview

A trial character is a Lv. 60 character played in a limited space, so you can see how a class plays in combat at higher levels. It receives exclusive equipment that only trial characters can wear, plus enough skill points to max out all skills. A trial character cannot enter a server where node wars and conquest wars take place.

## Trial Character creation and setup

To create one, press the Trial tab at the top right of the Character Selection screen, then log in with the new character. The nearby NPC Vendor for Trial Characters, Haz, sells several products. With the given gear, the total of AP and DP is about 620. After that, spend the given skill points to learn all available skills.

## Trial Character activities

After setting up a trial character, you can try skills on scarecrows or monsters placed around the area, duel other Adventurers in either the general arena or the 1 vs. 1 arena, and join the different Red Battlefield maps. The PvP, Skills, Battle Arena, and Red Battlefield pages give more detail on those contents.
