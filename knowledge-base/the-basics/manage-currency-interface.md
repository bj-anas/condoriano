# Manage Currency Interface

The Manage Currency interface is a menu that holds seals, tokens, and similar currency items outside your inventory and storage.

## Manage Currency Interface overview

Seals from worker tasks, Imperial Delivery, and Node/Conquest War, Coelacanths caught by fishing, and similar items are stored in the Manage Currency interface, not in your inventory or storage. You can view and exchange them directly in this interface, so you no longer need to visit NPCs in different places for related quests or exchanges.

## Manage Currency Interface access and favorites

To open the Manage Currency interface, click the Manage Currency icon at the top right of the screen. You can also go to Main Menu (Esc) > Rewards (F3) > Manage Currency Menu. To avoid scrolling a long list in the Manage Currency interface, mark items as favorites. Favorites appear at the start of the list and can also be filtered in the Favorites tab.
