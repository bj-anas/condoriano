# Customization

Character customization and the Beauty Salon, the menu used to change a character's look and voice.

## Customization overview

Character customization adjusts the look and voice of your character. You can change main features such as height, body size, hair, and face type, and finer details such as eye color, eyebrow length, skin gloss, and wrinkles. Before customizing, you can pre-dress the character in various clothes.

## Customization: Beauty Salon access and appearance changes

The customization interface is called the Beauty Salon. It is available while creating a character, and afterwards in the game by pressing F4 or choosing it from the main menu. After a character is created, changing its appearance again needs an Appearance Change Coupon or a Value Pack. Appearance Change Coupons can be bought in the Pearl Shop (hotkey: F3), and a Value Pack gives unlimited Beauty Salon access for its duration.

## Customization: Beauty Salon screen layout

Beauty Salon controls: Front view stops the face and eyes following the cursor; UI Toggle hides the UI for a clearer view; Take a screenshot saves to the screenshot folder, and another button opens that folder. Once the character exists, a "Take a portrait screenshot" option also appears; it replaces the picture shown in both the Character Profile and the End Game windows. Edit history stores each change (hair, face, and so on) with Undo and Redo. Other controls are Horoscope (constellation), Customization (hairstyle, face, body, voice), Weather (background), Character actions (clothes and pose), Customization information, and the character information menu, which shows the naming policy, finishes creation with a name, and goes back.

## Customization: hairstyle options

The hairstyle section changes type and color. Shape controls are Length 1 (front hair), Length 2 (side hair), Length 3 (upper hair), Curl strength (curl volume), and Curl level (number of curls). Some hairstyles limit lengths; certain short styles cannot set Length 3. Color has three parts: Base (color and gloss), Hair end (color, dyeing, and range), and Inner hair (color, inner dyeing, and inner range).

## Customization: face options

The face section covers Face type (default faces), Skin (color and shine of face and body), Makeup (eye makeup, eyebrows, blush, lips; menus differ for male and female), Facial Hair (beard, mustache, sideburns, brow, eyebrows), Face Shape (controllers for length, width, and depth of each part), Eyes (shape, color, and type, with pupil, iris, and lens adjusted separately), Eye lines (shape, length, and color of eyelashes and lines), Tattoo (size and position anywhere on the face), Wrinkles (brow, eye, and frown wrinkles to set apparent age), and Standby Expression, the default expression shown in the in-game idle motion.

## Customization: body and voice options

The body section has Shape (height, width, and other proportions), Muscle (torso, arms, and legs separately), Tattoo (size and position on the body), and Posture editing, which saves and deletes custom poses without affecting the in-game look. The Voice section sets the voice type and how deep or high the pitch is.

## Customization: controller

The customization controller adjusts a selected part by moving, rotating, or resizing, depending on the part. Pick a controller and click the part to move it directly, then fine-tune with the control bar for length, width, and depth. Each direction follows the screen view, not the character's facing.

## Customization: saving, loading, and Beauty Album

Customization information lives at the bottom left of the character creation screen. Save Temporarily keeps work in progress, up to 10 saves; after 10, the oldest is replaced. Save File stores the current look under a filename. Load File applies a file from another Adventurer or one you saved: overwrite the file in the customization folder, then click Load File in the game. Restore to Default returns the character to its initial look. Apply Most Popular applies the most popular Beauty Album look for that class. The Beauty Album lets you keep character pictures in the My Folder tab, upload to the Gallery to share, and browse or apply others' looks through the Popular Creators tab or the Gallery.
