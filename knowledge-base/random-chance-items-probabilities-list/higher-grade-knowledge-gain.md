# Higher Grade Knowledge Gain

How knowledge grades are rolled, the base chances per grade for basic and ecology knowledge, and how items change them.

## Higher Grade Knowledge Gain: how the grade is decided

Knowledge ranges from the highest grade, S, to the lowest default grade, C, and the grade is rolled with set probabilities. If you fail to get the top grade, the chance for the next grade down is applied, and this repeats until a final grade is set. Example: failing S leads to the A+ roll, failing A+ leads to the B roll, and so on.

## Higher Grade Knowledge Gain: basic knowledge grade probabilities

Chance of each grade for basic knowledge. The "@" stands for a bonus from items with a Higher Grade Knowledge Gain Chance effect, such as Round Earrings and Looney Elixir.

| Grade | Probability |
|---|---|
| S | 1% + @ |
| A | 6% + @ |
| B | 16% + @ |
| C | 46% + @ |
| D | Obtained after failure of all other grades |

## Higher Grade Knowledge Gain: ecology knowledge grade probabilities

Chance of each grade for ecology knowledge. The "@" is the same Higher Grade Knowledge Gain bonus.

| Grade | Probability |
|---|---|
| S | 1% + @ |
| A+ | 6% + @ |
| A | 16% + @ |
| B | 46% + @ |
| C | Obtained after failure of all other grades |

Example: wearing Round Earrings raises the chance of S grade knowledge to 6% (1% + 5%).

## Higher Grade Knowledge Gain: basic knowledge acquisition rate boost

Items like Ellen Glasses and Weenie Elixir, whose description says Knowledge Gain Chance +50%, raise the basic knowledge acquisition rate proportionally. Example: Monster A has a 40% basic knowledge acquisition rate. With Ellen Glasses, the rate is 40% + (50% x 40%) = 60%.
