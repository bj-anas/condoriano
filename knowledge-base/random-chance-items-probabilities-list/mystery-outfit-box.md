# Mystery Outfit Box

Everything the Mystery Outfit Box can give, with chances.

## Mystery Outfit Box: what it is and how to get it

The Mystery Outfit Box is listed in the Random Chance Items & Probabilities List. The wiki page gives only its contents and chances, not where it is sold or obtained. The chances in the table add up to 100%, so each box opened gives one reward. Quantities are part of the item name.

## Mystery Outfit Box: possible rewards and probabilities

Each opening of the Mystery Outfit Box gives one of these rewards.

| Item Name | Probability |
|---|---|
| [Event] Premium Outfit Box x10 | 0.5% |
| [Event] Classic Outfit Box x7 | 1.0% |
| [Event] Succession Classic Box x5 | 1.5% |
| Mystery Outfit Box x3 | 2.0% |
| [Event] Premium Outfit Box x2 | 4.0% |
| [Event] Classic Outfit Box x1 | 8.0% |
| [Event] Succession Classic Box x1 | 8.0% |
| Artisan's Memory x35 | 35.0% |
| Cron Stone x250 | 40.0% |

## Mystery Outfit Box: notes

The most likely reward of the Mystery Outfit Box is Cron Stone x250 at 40.0%, then Artisan's Memory x35 at 35.0%. The rarest is [Event] Premium Outfit Box x10 at 0.5%. The box can also give more of itself: Mystery Outfit Box x3 at 2.0%.
