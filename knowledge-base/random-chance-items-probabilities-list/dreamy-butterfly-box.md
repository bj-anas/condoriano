# Dreamy Butterfly Box

How the Dreamy Butterfly Box leads to the Radiant, Vivid and Faint Dream Boxes, what each of them can give, and how Dreamer's Seals are exchanged.

## Dreamy Butterfly Box: what it is and how to get it

The Dreamy Butterfly Box is an item listed in the Random Chance Items & Probabilities List. Opening it gives 1 of 3 Dream Boxes with a set probability. A Dreamy Butterfly Box can also be obtained for 10 Dreamer's Seals through the Manage Currency UI.

## Dreamy Butterfly Box: possible rewards and probabilities

| Item Name | Qty | Probability |
|---|---|---|
| Radiant Dream Box | 1 | 10.00% |
| Vivid Dream Box | 1 | 30.00% |
| Faint Dream Box | 1 | 60.00% |

## Dreamy Butterfly Box: Radiant Dream Box probabilities

The Radiant Dream Box, a 10.00% result of the Dreamy Butterfly Box, gives 1 of the following with a set probability.

## Dreamy Butterfly Box: Dreamer's Seal exchange

Dreamer's Seals are used from your Pearl Inventory, which registers them in the Manage Currency UI. Registered seals can then be exchanged for these rewards in the Manage Currency UI.

| Item Name | Required Seals | Family Exchange Limit |
|---|---|---|
| Ultimate Premium Enhancement Box | 15 | 1 |
| Transcended Premium Enhancement Box | 50 | - |
| Ultimate Premium Enhancement Box | 35 | - |
| Radiant Dream Box | 20 | - |
| Dreamy Butterfly Box | 10 | - |
| Box of 30 Cron Stones | 1 | - |
