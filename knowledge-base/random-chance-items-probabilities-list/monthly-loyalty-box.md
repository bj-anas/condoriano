# Monthly Loyalty Box

Everything the Monthly Loyalty Box can give, with amounts and chances.

## Monthly Loyalty Box: what it is and how to get it

The Monthly Loyalty Box is listed in the Random Chance Items & Probabilities List. The wiki page gives only its contents and chances, not where it is sold or obtained. The chances in the table add up to 100%, so each box opened gives one reward, in the amount shown.

## Monthly Loyalty Box: possible rewards and probabilities

Each opening of the Monthly Loyalty Box gives one of these rewards.

| Item Name | Amount | Chance |
|---|---|---|
| [Event] Premium Outfit Box | x1 | 1% |
| Mount Skill Change Coupon | x3 | 5% |
| Inventory +8 Expansion Coupon | x1 | 10% |
| Value Pack (1 Day) | x1 | 12% |
| [Event] Blessing of Kamasylve (1 Day) | x1 | 12% |
| [Event] Secret Book of Old Moon (1 Day) | x1 | 12% |
| Artisan's Memory | x5 | 48% |

## Monthly Loyalty Box: notes

The most likely reward of the Monthly Loyalty Box is Artisan's Memory x5 at 48%. The rarest is [Event] Premium Outfit Box x1 at 1%. Value Pack (1 Day), [Event] Blessing of Kamasylve (1 Day) and [Event] Secret Book of Old Moon (1 Day) are each 12%.
