# Special ADV Manual Box

How to get the [Event] Special ADV Manual Box and which Old Moon manuals it can give.

## Special ADV Manual Box: what it is and how to get it

The [Event] Special ADV Manual Box is an event item listed in the Random Chance Items & Probabilities List. You get it from the event UI after obtaining an [Event] Crash Course Ticket, either through the Pearl Shop or through an event. The event UI is the Old Moon ADV Crash Course UI.

## Special ADV Manual Box: possible rewards and probabilities

The box gives one of the following at a set probability.

| Item | Qty | Probability |
|---|---|---|
| Old Moon Manual (Subjugation) | 1 | 20% |
| Old Moon Manual (Gathering) | 1 | 20% |
| Old Moon Manual (Training) | 1 | 20% |
| Old Moon Manual (Hunting) | 1 | 20% |
| Old Moon Manual (Farming) | 1 | 20% |

## Special ADV Manual Box: notes

This [Event] Special ADV Manual Box is a different item from the one in the Old Moon Guild: Classes are in Session! event of March 13, 2024.
