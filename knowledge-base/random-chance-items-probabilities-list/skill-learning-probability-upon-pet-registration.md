# Skill Learning Probability upon Pet Registration

Chances for a Pearl Shop pet to learn each Main Skill when it is registered, by pet tier and pet type, with the number of Main Skills per tier.

## Pet skills at registration: Main Skills, Talents and how many a pet learns

Every pet has one Talent unique to it, one Special Ability, and a set of Main Skills whose count depends on its tier. The Talent is guaranteed by pet type. How many Main Skills a pet can learn, and the chance of each, depends on its tier and type. In the pet UI, the Talent is shown at the far right with the Main Skills to its left. The number of Main Skills a pet can learn is: Tier 1, 1 skill; Tier 2, 1 skill; Tier 3, 2 skills; Tier 4, 3 skills. Pets learn Main Skills up to that number when you use Register Pet or Exchange Pet.

## Pet skills at registration: where to find the probabilities

The chance of each Main Skill when exchanging a pet can be viewed through Skill Learning Chance after registering a pet, by going to Pet, then Exchange, then Register Pet. The chance of each Main Skill when registering a pet bought from the Pearl Shop is listed on the wiki by pet name and tier. Percentages with more than five decimal places are rounded to four decimal places. A pet cannot learn the same skill twice. A Tier 3 pet learns two skills, so its table adds up to 200%, and a Tier 4 pet learns three skills, so its table adds up to 300%.
