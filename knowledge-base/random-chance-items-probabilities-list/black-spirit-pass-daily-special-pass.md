# Black Spirit Pass / Daily Special Pass

Probability tables for the Black Spirit Pass / Daily Special Pass event boxes and chests (the Shakatu boxes), with quantities and chances.

## Black Spirit Pass / Daily Special Pass: what it is

The Black Spirit Pass / Daily Special Pass is listed as an event entry in the Random Chance Items & Probabilities List. These passes can only be bought from the Pearl Shop during a certain period. The wiki page gives the probability tables for the items you can obtain from them: [Event] Shakatu's Resplendent Box, [Event] Shakatu's Chest of Shinies, [Event] Shakatu's Luxury Box, [Event] Shakatu's Chest of Rarities, [Event] Shakatu's Chest of Luxuries, [Event] Shakatu's Shiny Box (Combat), [Event] Shakatu's Shiny Box (Life) and the Memory Fragment Bundle. The probabilities are rounded to the fourth decimal place.
