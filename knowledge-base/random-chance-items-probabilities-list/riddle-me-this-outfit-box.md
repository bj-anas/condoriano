# Riddle-Me-This Outfit Box

Everything the Riddle-Me-This Outfit Box can give, with chances.

## Riddle-Me-This Outfit Box: what it is and how to get it

The Riddle-Me-This Outfit Box is listed in the Random Chance Items & Probabilities List. The wiki page gives only its contents and chances, not where it is sold or obtained. It has eight possible results with equal chances that add up to 100%, so each box opened gives one outfit box result. Quantities are part of the item name.

## Riddle-Me-This Outfit Box: possible rewards and probabilities

Each opening of the Riddle-Me-This Outfit Box gives one of these rewards.

| Item Name | Probability |
|---|---|
| Reboot Premium Outfit Box x2 | 12.5% |
| Premium Outfit Box II x2 | 12.5% |
| Classic Outfit Box x2 | 12.5% |
| Succession Classic Box x2 | 12.5% |
| Reboot Premium Outfit Box x1 | 12.5% |
| Premium Outfit Box II x1 | 12.5% |
| Classic Outfit Box x1 | 12.5% |
| Succession Classic Box x1 | 12.5% |

## Riddle-Me-This Outfit Box: notes

Every reward of the Riddle-Me-This Outfit Box has the same 12.5% chance. The four box types are Reboot Premium Outfit Box, Premium Outfit Box II, Classic Outfit Box and Succession Classic Box, each in a quantity of 1 or 2.
