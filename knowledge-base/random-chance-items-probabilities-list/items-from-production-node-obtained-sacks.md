# Items from Production Node Obtained Sacks

What each production node sack (Farmer's, Miner's, Archaeologist's and Fisher's) can give, with chances.

## Production node sacks: how they work

Using a sack obtained from a production node gives one of the items listed for that sack, at the set probabilities. There are four sacks: Some Farmer's Sack, Some Miner's Sack, Some Archaeologist's Sack and Some Fisher's Sack.

## Some Farmer's Sack: possible items and probabilities

Some Farmer's Sack gives one of eight fruits, each with the same chance.

| Obtainable item | Probability (%) |
|---|---|
| Fruit of Crimson Flame | 12.5000 |
