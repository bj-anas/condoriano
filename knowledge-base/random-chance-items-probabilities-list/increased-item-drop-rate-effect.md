# Increased Item Drop Rate Effect

How the Increased Item Drop Rate effect of Item Collection Increase Scrolls is calculated, and where to activate it.

## Increased Item Drop Rate Effect: formula

Items such as the Item Collection Increase Scroll and the Item Collection Increase Scroll: Advanced raise the item drop rate. An increase of +n% adds an amount proportional to the item's original drop rate, not a flat n percentage points. Example: with an Item Collection Increase Scroll of +100% active, an item with a 1% base drop rate gets 100% of that 1% added, so its overall drop rate becomes 2%.

## Increased Item Drop Rate Effect: how to activate and gauge levels

Item Collection Increase Scrolls are activated in the game UI through Menu (Esc), then Adventure (F5), then Item Collection Increase Scroll. Gauge Lv. 1 and Lv. 2 of the Item Collection Increase Scroll give an identical drop rate bonus. Switching to Lv. 2 only raises the Item Drop Amount, from 50% to 100%.
