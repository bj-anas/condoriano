# Tidal Treasure Chest

How the Tidal Treasure Chest chain works, with the chance at each stage, the Briny Blue Badge exchange and the contents of the Premium Enhancement Boxes.

## Tidal Treasure Chest: what it is and how to get it

The Tidal Treasure Chest is listed in the Random Chance Items & Probabilities List. The wiki page gives only its contents and chances, not where it is sold or obtained. It works in stages: Tidal Treasure Chest, Faded, Glimmering, Brilliant and Splendid treasure chests. Each stage gives either the next chest or a pouch of rewards, and a Tidal Treasure Chest can also be won again from the Brilliant Treasure Chest.

## Tidal Treasure Chest: possible rewards and probabilities

The "Stage chance" column is the chance at that chest. The "Final chance" column is the chance of ending with that result when opening one Tidal Treasure Chest. Each pouch gives all of its items when opened.

| Chest | Contents | Stage chance | Final chance |
|---|---|---|---|
| Tidal Treasure Chest | Faded Treasure Chest x1 | 40% | - |
| Tidal Treasure Chest | Faint Light Pouch x1 (Cron Stone x150, Briny Blue Badge x1) | 60% | 60% |
| Faded Treasure Chest | Glimmering Treasure Chest x1 | 50% | - |
| Faded Treasure Chest | Glimmering Light Pouch x1 (Cron Stone x250, Advice of Valks (+50) x1, Briny Blue Badge x2) | 50% | 20% |
| Glimmering Treasure Chest | Brilliant Treasure Chest x1 | 55% | - |
| Glimmering Treasure Chest | Brilliant Light Pouch x1 (Cron Stone x350, Artisan's Memory x10, Advice of Valks (+60) x1, Briny Blue Badge x3) | 45% | 9% |
| Brilliant Treasure Chest | Splendid Treasure Chest x1 | 60% | - |
| Brilliant Treasure Chest | Tidal Treasure Chest x2 | 40% | 4.4% |
| Splendid Treasure Chest | Ultimate Premium Enhancement Box x1 | 60% | 3.96% |
| Splendid Treasure Chest | Radiant Treasure Pouch x1 (Cron Stone x500, Artisan's Memory x20, Advice of Valks (+80) x1, Briny Blue Badge x6) | 40% | 2.64% |

## Tidal Treasure Chest: exchanging Briny Blue Badges

Briny Blue Badges, which come from the pouches of the Tidal Treasure Chest, can be exchanged at any time through the Blacksmith Tranan Underfoe in Velia.

| Required Badges | Item received |
|---|---|
| 70 | Transcended Premium Enhancement Box x1 |
| 35 | Ultimate Premium Enhancement Box x1 |
| 15 | Sweet Premium Enhancement Box x1 |
| 5 | Tidal Treasure Chest x1 |
| 1 | Box of 20 Cron Stones x1 |

## Tidal Treasure Chest: notes

Overall odds from the first Tidal Treasure Chest: Faint Light Pouch at 60%, Glimmering Light Pouch at 20%, Brilliant Light Pouch at 9%, Tidal Treasure Chest x2 at 4.4%, Ultimate Premium Enhancement Box at 3.96% and Radiant Treasure Pouch at 2.64%. The Tidal Treasure Chest x2 result restarts the chain.
