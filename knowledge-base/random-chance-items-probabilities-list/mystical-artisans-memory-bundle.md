# Mystical Artisan's Memory Bundle

Rewards and chances for the Mystical Artisan's Memory Bundle: Artisan's Memory, Cron Stone and Memory Fragment amounts.

## Mystical Artisan's Memory Bundle: what it is and how to get it

The Mystical Artisan's Memory Bundle is a Pearl Shop item listed in the Random Chance Items & Probabilities List. Opening it gives one item and amount from the table. It is also one of the rewards of the Black Tiger Pouch of Fortune.
