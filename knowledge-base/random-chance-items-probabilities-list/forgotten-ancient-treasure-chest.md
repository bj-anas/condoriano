# Forgotten Ancient Treasure Chest

How the Forgotten Ancient Treasure Chest chain works, what the Ancient Treasure Chests contain, how Faded Golden Seals are exchanged, and the contents of the Radiant Glyph Treasure Chest and Premium Enhancement Boxes.

## Forgotten Ancient Treasure Chest: what it is and how to get it

The Forgotten Ancient Treasure Chest is a Pearl Shop item that is on sale only for a limited time. It works in stages through the Faint, Glimmering, Brilliant, Precious and Radiant Glyph Treasure Chests. A Forgotten Ancient Treasure Chest can also be obtained for 5 Faded Golden Seals.

## Forgotten Ancient Treasure Chest: possible rewards and probabilities

The "per stage" column is the chance at that stage. The "total" column is the overall chance of ending with that reward.

| Chest | Content | Per stage | Total |
|---|---|---|---|
| Forgotten Ancient Treasure Chest | Faint Glyph Treasure Chest x1 | 50% | - |
| Forgotten Ancient Treasure Chest | Ancient Treasure Chest (S) x1 | 50% | 50% |
| Faint Glyph Treasure Chest | Glimmering Glyph Treasure Chest x1 | 50% | - |
| Faint Glyph Treasure Chest | Ancient Treasure Chest (M) x1 | 50% | 25% |
| Glimmering Glyph Treasure Chest | Brilliant Glyph Treasure Chest x1 | 50% | - |
| Glimmering Glyph Treasure Chest | Forgotten Ancient Treasure Chest x1 | 25% | 6.25% |
| Glimmering Glyph Treasure Chest | Forgotten Ancient Treasure Chest x2 | 25% | 6.25% |
| Brilliant Glyph Treasure Chest | Precious Glyph Treasure Chest x1 | 50% | - |
| Brilliant Glyph Treasure Chest | Ancient Treasure Chest (L) x1 | 50% | 6.25% |
| Precious Glyph Treasure Chest | Radiant Glyph Treasure Chest x1 and Faded Golden Seal x5 | 100% | 6.25% |

## Forgotten Ancient Treasure Chest: contents of the Ancient Treasure Chests

Opening any of these gives all of the items listed.

- Ancient Treasure Chest (S): Cron Stone x150, [Event] Dim Origin of Dark Hunger x1, Memory Fragment x10, Faded Golden Seal x1.
- Ancient Treasure Chest (M): Cron Stone x250, [Event] Dim Origin of Dark Hunger x1, Memory Fragment x20, Faded Golden Seal x2.
- Ancient Treasure Chest (L): Cron Stone x500, [Event] Dim Origin of Dark Hunger x3, Memory Fragment x40, Faded Golden Seal x3.

## Forgotten Ancient Treasure Chest: Faded Golden Seal exchange

Faded Golden Seals from the Forgotten Ancient Treasure Chest are registered in your Pearl Inventory and then exchanged through Manage Currency. Items exchanged with Faded Golden Seals are tax-exempt.

| Seals to exchange | Item received |
|---|---|
| 70 | Transcended Premium Enhancement Box x1 |
| 30 | Radiant Glyph Treasure Chest x1 |
| 15 | Sweet Premium Enhancement Box x1 |
| 5 | Forgotten Ancient Treasure Chest |
| 1 | Box of 20 Cron Stones x1 |
