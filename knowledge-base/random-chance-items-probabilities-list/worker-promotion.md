# Worker Promotion

Success chances for worker promotion tests, by worker grade, from the official wiki.

## Worker Promotion: what it is

Worker Promotion is an in-game system covered in the Random Chance Items & Probabilities List. The wiki lists the base success chance of each promotion test, based on set probabilities, and the chance goes down for higher worker grades.

## Worker Promotion: success probability by worker grade

| Promotion test | Promotion probability |
|---|---|
| Skilled Worker Promotion Test | 90% |
| Professional Worker Promotion Test | 70% |
| Artisan Worker Promotion Test | 50% |
