# Dye Boxes

Probabilities of the dyes you can get from each color dye box and each Unknown Dye Box on the official wiki, shown by dye type and shade.

## Dye Boxes: overview of the boxes and dye types

The Dye Boxes page lists the chance of every dye you can get from each color box and each unknown dye box. Opening a box gives one dye, and the percentages of each box add up to 100%. There are ten color boxes: Red Dye Box, Orange Dye Box, Yellow-Brown Dye Box, Lime Dye Box, Mint Dye Box, Aqua Dye Box, Turquoise Dye Box, Blue Dye Box, Purple Dye Box and Pink Dye Box. There are eight unknown dye boxes, one for each dye type: Unknown Dye Box [Valencian], [Mediahn], [Calpheonian], [Keplanian], [Heidelian], [Velian], [Olvian] and [Basic]. The dye types are Olvian, Velian, Heidelian, Keplanian, Calpheonian, Mediahn, Valencian and Basic, written like [Olvian Dye] True Red.

## Dye Boxes: how the color box tables are laid out

In each color box, the non-Basic dyes come in 12 shades: True, Soft, Vivid, Pure, Brilliant, Original, Wine, Shining, Sunshine, Gloomy, Shadow and Snow. Each shade has one dye for each of the seven types Olvian, Velian, Heidelian, Keplanian, Calpheonian, Mediahn and Valencian. In these notes each color box has a grid of shade by dye type and a separate list of the Basic Dyes in that box. The Turquoise Dye Box uses the color name Sky, the Blue Dye Box uses Indigo and the Pink Dye Box uses Deep Pink in its dye names, and the Yellow-Brown Dye Box uses Yellow.
