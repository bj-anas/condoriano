# Treasure Merchant's Secret Box

How the Treasure Merchant's Secret Box chain works, with the chance at each stage and the full contents of the three bundles it can give.

## Treasure Merchant's Secret Box: what it is and how to get it

The Treasure Merchant's Secret Box is listed in the Random Chance Items & Probabilities List. The wiki page gives only its contents and chances, not where it is sold or obtained. It works in stages: Treasure Merchant's Secret Box, then the Rare Box and the Prized Box. The result is one of three bundles (Shiny, Resplendent or Splendid) or more Secret Boxes.

## Treasure Merchant's Secret Box: possible rewards and probabilities

The "Stage chance" column is the chance at that box. The "Final chance" column is the chance of ending with that result when opening one Treasure Merchant's Secret Box.

| Box | Contents | Stage chance | Final chance |
|---|---|---|---|
| Treasure Merchant's Secret Box | Treasure Merchant's Rare Box x1 | 50% | - |
| Treasure Merchant's Secret Box | Treasure Merchant's Shiny Bundle x1 | 50% | 50% |
| Treasure Merchant's Rare Box | Treasure Merchant's Prized Box x1 | 50% | - |
| Treasure Merchant's Rare Box | Treasure Merchant's Resplendent Bundle x1 | 50% | 25% |
| Treasure Merchant's Prized Box | Treasure Merchant's Splendid Bundle x1 | 55% | 13.75% |
| Treasure Merchant's Prized Box | Treasure Merchant's Secret Box x2 | 45% | 11.25% |

## Treasure Merchant's Secret Box: notes

Overall odds from the first Treasure Merchant's Secret Box: Shiny Bundle at 50%, Resplendent Bundle at 25%, Splendid Bundle at 13.75% and Treasure Merchant's Secret Box x2 at 11.25%. The x2 result restarts the chain. All three bundles can also give more Treasure Merchant's Secret Boxes as bonus items.
