# Installation Guide

Step-by-step instructions for downloading, installing and starting Black Desert from the official website.

## How to download and install Black Desert

To install Black Desert, follow these steps:

1. On the official Black Desert website, hover over Download and click the Client menu.
2. Click the Download Client button in the middle of the page. When the download finishes, double-click the downloaded file to start installing.
3. In the Setup Wizard, follow the on-screen instructions. After installation, launch the game file BlackDesertLauncher.exe, from the bottom of your screen or from the game's installation folder.

## Logging in and starting Black Desert after installation

After opening BlackDesertLauncher.exe, log in. If you do not have an account yet, click the Sign up button to create one. Then pick your region from the Select Region menu and press the Start Game button to begin your adventure.
