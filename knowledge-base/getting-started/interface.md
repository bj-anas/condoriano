# Interface

The Black Desert heads-up display (HUD), the Edit UI interface edit mode, and the Sticker UI feature that moves windows outside the game.

## HUD top left corner

The top left corner of the Black Desert HUD shows a diamond with your character's level and experience progress (as a percentage and as a bar around the diamond). To its left is the PvP activation icon (a sword and shield). To its right are the HP and class resource (MP, WP, etc.) bars. Above those bars, small icons display your skill points, character energy and family contribution points. Next to them are status icons for active bonuses: drop rate bonuses, EXP boost, node investment benefit, Secret Book of Old Moon, Kamasylve's Blessing, Value Pack, and Agris Fever (once unlocked via quests). Below the bars is the red Black Spirit's Rage bar, and under it icons for your land mount or boat, residences, workers, pets, maids and butlers, campsite, tagged characters, fairy and fishing rod. Some icons appear only after unlocking the content.

## HUD top right corner

The top right corner of the Black Desert HUD holds server information, the minimap and quests. Icons to the left of the minimap are shortcuts to the Find NPC tool, the video guide, voice chat status, node installation areas for Node Wars, the Old Moon Grand Prix horse racing mode, and the Progression Pass for non-season characters. Above the minimap are the terrain type, weather, Node War status, Conquest construction status, your server and the in-game time. The minimap can be shown as a 2D top-down view or in 3D mode. During World Boss encounters a Boss Vision Range toggle appears left of the minimap to raise the maximum vision range. The quest tracker is below the minimap.

## HUD bottom right, bottom middle and bottom left

The bottom right of the Black Spirit HUD has notification widgets. They open the Black Spirit's Safe (daily login and Black Spirit's Adventure rewards), the list of open Dark Rifts, the Black Spirit interface, the Challenges reward window, the Main feature, your skills window, and the list of hunting targets across the world for the hunting Life Skill. To their right are the quest window, Central Market notifications, the Pearl Shop and the game's settings. The bottom middle shows the default action hotkeys and the active buffs and debuffs on your character. By default, the chat windows occupy the bottom left.

## Edit UI interface edit mode

Edit UI lets you customize the position and visibility of HUD elements. Start it by clicking Edit UI in the main menu (hotkey: Esc), in either the new or old main menu. In edit mode, sections shown in white are visible and can be hidden or moved. Sections in transparent black are hidden and can be shown or moved. Sections in red can be shown or hidden but cannot be moved. Click the eye symbol on a window to turn it on or off. "Show Grid" displays grid lines for precise placement, and Auto-align Slot helps place 20 separate quick slots at the same interval as an adjacent slot.

## Saving Edit UI presets

In Edit UI you can save your changes with Save (ENTER), or save the interface as a preset to recall later. You can also pick a combat-focused preset and alter it further. To reapply a stored preset, first reset the interface, then load the chosen preset.

## Sticker UI and the windows that support it

Sticker UI moves some in-game windows outside the game so you can use your screen better. Click the Sticker UI button at the top right of a window to enable it. The window disappears from the game and an exact copy appears at the front of the screen, which you can drag by its title bar, even outside the game. It stays visible while the game is not minimized or closed. It darkens when you open an in-game window that blocks it, for example the World Map (hotkey: M) over a Quest window (hotkey: O). Not all features of the window work in Sticker UI. Close it by clicking the Sticker UI button to return it to the game or the "X" button. It closes automatically when you change servers or revive. Windows that support Sticker UI, in alphabetical order: Adventurer's Board, Barter Information, Black Spirit's Adventure, Crafting Notes, Equipment, Guild, Inventory, My Information, Quests, Trade Info, and Worker List.
