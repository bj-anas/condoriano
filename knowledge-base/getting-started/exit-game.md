# Exit Game

The End Game window is used to shut down the client or switch characters. This page also covers changing character order, character portraits and Privacy Mode.

## End Game window overview

The End Game window is the menu used when you shut down the client or change to another character. Open it from the main menu (hotkey: Esc). A button switches the character display between a simplified and a detailed interface, and clicking it shows all characters on your account in a single interface.

## End Game window buttons

The End Game window has these buttons:

- Character Selection: returns to the character selection window, to move to another character on the same server or create a new one. A quick relog this way also refreshes the visibility of feature and event rewards and Pearl Shop offers.
- Change Server: opens the server list. After changing server you must wait 10 minutes before changing to another one. A guild can select 3 guild base servers, and members can switch between those 3 without cooldown.
- Minimize to Tray: sends the game to the system tray so workers, crafting and farms keep progressing while it uses minimal resources. Click the Black Desert icon in the tray to reopen it. Alt + LMB on the button assigns a hotkey to it.
- Disconnect: exits the game client.

## Switching characters from the End Game window

The Change button in the End Game window switches character without going through character selection. It shows the status and location of the character you will change to. If the character you switch to is busy with an action such as being transported, self-repairing, reading a book or resting on a bed, that action continues until the next login. You can switch to any character above level 5. The box button left of Change, View Character's Inventory, shows the inventory of all your characters. With storage maids or butlers you can move items from other characters' inventory and pearl inventory to your current character.

## Information on character portraits in the End Game window

Each character's portrait in the End Game window shows extra information. Energy points appear at the bottom left, which helps when you need several characters to spend a lot of Energy. The enhancement chance appears at the bottom right. A horse icon at the top right means the character has a mount out, and hovering shows the mount's name, type, level and tier. During an ongoing season, a season character shows the season icon at the top left. The window also lists the character's Recently Completed Quest and Today's Journal, a list of the major events the character last experienced.

## Changing character order

To change the order of characters on the character selection screen and End Game window, use Change Character Order at the bottom right of the character selection screen. ▲▼ buttons then appear beside each character to move it up or down. You can also do this from the End Game UI with its icon. Select the character to move, then select the target position character. The moved character goes in front of the target and the others shift back one spot. Moving A onto B in the order A, B, C, D changes nothing, so use a swap method to reorder.

## Changing character portraits

Character portraits in the End Game window can be customized. Press F4 to open the customization screen, finish the appearance, then press the Take Portrait button at the top left. Portrait pictures are stored in the My Documents > Black Desert > FaceTexture folder. To use a custom image, put it in that folder and rename the file to the name of the class's current portrait file.

## Privacy Mode

Privacy Mode, found next to the Change Character Order button, hides your login status from other Adventurers. While it is active you appear offline to friends, guild members and others in most functions, and you may be restricted from guild or friend invites and other functions. Your name still shows in system messages when you kill or get killed in PvP. System messages such as enhancement results show your name as "Unknown Adventurer".
