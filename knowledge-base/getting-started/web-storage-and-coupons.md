# Web Storage and Coupons

How to send event rewards from the Web Storage on the official website to your in-game mailbox, and how to register coupon codes on the website or in the game.

## What the Web Storage is

The Web Storage is on the My Page of the official Black Desert website. It stores various event rewards, including items from redeemed coupons. You pick which Family and character should get the rewards, which arrive as in-game mail.

## How to send an item from the Web Storage to your in-game mailbox

To send a Web Storage item to the game, follow these steps:

1. On the official website, use the Web Storage link in the left menu of My Page, or take the route My Page > Web Storage (center) > Black Desert NA/EU.
2. Pick the Web Storage entry you want.
3. Select the server and character to receive the item and click Next.
4. Check that the item, server and character are correct. Click Cancel if not, or Send Item if so.
5. The confirmation screen lists the items sent to the in-game mailbox.
6. In the game, open your mailbox (B) to see the item.

## Registering a coupon on the official website

You can register a coupon on the official website when you cannot load the game and want to redeem it in advance. Log in, then choose Shop > Redeem Coupon from the top drop-down menu. The other route is My Page > Use Black Desert Coupon > Go to Coupon. Type the 16-digit coupon code exactly and click Use. Then go to My Page > Web Storage: if the item is there, the coupon was redeemed. Send it from the Web Storage to your mailbox.

## Redeeming a coupon in the game

To redeem a coupon in the game, log in with the character that should get the reward, open the menu (ESC), click Adventurer Support > Use Coupon, type the exact code, and click Use. The item is sent directly to your in-game mailbox without visiting the website.

## Coupon redemption rules

Coupon rules in Black Desert: a coupon counts only if Pearl Abyss issued it. A code is a 16-digit alphanumeric key. Expiration dates vary by event. Identity fraud can lead to restrictions on using the service. Entering a coupon code wrongly 10 times in a row causes a 1-hour block on the coupon.
